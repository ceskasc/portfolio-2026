<h2 id="kurulum">
  KURULUM VE CALISTIRMA
</h2>

<h3>
  1) Projeyi klonla
</h3>

```bash
git clone https://github.com/ceskasc/portfolio-2026.git
cd portfolio-2026
```

<h3>
  2) Basit lokal sunucu ile ac
</h3>

```bash
# Python
python -m http.server 5500

# Node (opsiyonel)
npx serve .
```

<h3>
  3) Tarayicida test et
</h3>

```text
http://localhost:5500
```
